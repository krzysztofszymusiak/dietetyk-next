# Dietetyk – Kuba Ciesielski (Next.js)
npm install
npm run dev   # http://localhost:3000

## Płatności Przelewy24
1. cp .env.example .env.local  i uzupełnij klucze (sandbox)
2. Webhook wymaga publicznego adresu – lokalnie użyj tunelu (np. ngrok http 3000) i wpisz go w SITE_URL
3. Zrestartuj npm run dev
